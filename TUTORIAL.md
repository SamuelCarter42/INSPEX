This tutorial aims to walk you through the basics of analysis with INSPEX. 
We will be using the 09/10/2021 event as an example in this tutorial, and analysing the event using the GUI method.

Step 1: Initialise INSPEX
After installing INSPEX, open and run inspex.py. This sets up the INSPEX environment, defining the functions that will be required for the rest of the process.

Step 2: Defining the time and spectral type
To begin analysis, run instrument_choice() at the command line. this brings up a window from which you may choose the instrument data, date range of interest, spectrum type and resampling for the analysis.
